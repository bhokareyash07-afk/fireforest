Section D

Descriptive analysis

The system corrected supported image orientation on upload and compared both images in a common {{ analysis.dimensions.analyzed_width }} × {{ analysis.dimensions.analyzed_height }} pixel frame. {{ analysis.pipeline.resize_note }} Noise reduction was applied with edge-preserving and Gaussian smoothing before a pixel-level L*a*b* colour-distance comparison.

{{ analysis.pipeline.alignment_note }} Pixels at or above the configured change threshold were treated as significant visual change. The processed difference values were split into mutually exclusive lower (blue), moderate (yellow), and highest (red) categories; every detected-change pixel belongs to exactly one category.

The generated heatmap overlays these masks on the post-fire image. Section F

Limitations

This system identifies visual changes between two images. Changes may also result from lighting, shadows, seasons, image alignment, camera angle, or other environmental factors. The heatmap is a preliminary image-change assessment and does not independently confirm burned vegetation or ecological damage. Field verification is required before restoration decisions.
