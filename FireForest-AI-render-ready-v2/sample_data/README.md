# Test-image sources

The automated tests generate their own synthetic image pairs so the repository remains small. For realistic manual validation, download two photographs that you have the right to use, then use the same location/angle where possible.

- [NASA Earth Observatory image archive](https://earthobservatory.nasa.gov/images) — see [NASA's media-use guidance](https://www.nasa.gov/nasa-brand-center/images-and-media/) before selecting an image.
- [Wikimedia Commons forest-fire media](https://commons.wikimedia.org/wiki/Category:Forest_fires) — select individual files whose licence suits your use and retain attribution required on that file's page.
- [Wikimedia Commons forest photographs](https://commons.wikimedia.org/wiki/Category:Forests) — similarly, confirm the licence shown for each selected image.

Manual validation checklist: test a healthy forest, a burned/charred forest, two unrelated images, one forest plus one unrelated image, differing dimensions, a corrupt file, and an unsupported extension.
