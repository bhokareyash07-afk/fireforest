# Image assets

The welcome page uses a remote forest photograph from Unsplash's CDN. The source photograph is by [Casey Horner on Unsplash](https://unsplash.com/photos/4rDCa5hBlCs) and is made available under the [Unsplash License](https://unsplash.com/license).

To add the official college logo, place an appropriately authorized image at `static/images/college-logo.png`. It will appear in the reserved welcome-page logo space. No college logo is included in this project.
